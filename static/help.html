1. 한눈에 보기

VisionMeeting 은 여러 나라 사무실을 잇는 화상회의 + 실시간 번역 자막 프로그램입니다. 브라우저만 있으면 됩니다.

  • 한 회의에 PC(«지점») 4곳까지 접속합니다. 회의실 PC 한 대 앞에 여러 명이 함께 앉아도 됩니다.
  • 모든 지점은 원래 목소리로 자유롭게 대화합니다. 버튼을 누를 필요가 없습니다. 마이크가 켜져 있으면 말한 내용이 자동으로 글자로 바뀌고, 각 지점의 언어로 번역된 자막이 뜹니다(«자동 자막»).
  • 여러 지점이 동시에 말해도 지점마다 자막이 나옵니다. 다만 섞여서 읽기 어려우니 한 지점씩 말하는 것이 좋습니다.
  • 지점마다 언어 1개를 고르고, 한 회의에서 쓸 수 있는 언어는 최대 3개입니다.

쓸 수 있는 언어

  • 한국어
  • English
  • Tiếng Việt
  • 中文(简体)
  • 日本語

«미검증» 이 붙은 언어는 실제 회의에서 인식·번역 품질을 아직 확인하지 않은 언어입니다.

2. 준비물과 처음 한 번 설정

  • PC 와 최신 Chrome 또는 Edge. 음성 인식과 번역을 브라우저 기능으로 처리하므로, 다른 브라우저나 휴대폰에서는 자막이 동작하지 않을 수 있습니다. (휴대폰은 현장 카메라 용도로만 씁니다.)
  • 카메라, 마이크, 스피커(또는 이어폰). 카메라가 없어도 마이크만으로 참여할 수 있습니다.
  • 접속 주소 — 사내망: https://<서버 IP>:8443 / 외부: Host 가 보내 준 https://…trycloudflare.com 링크

사내망 PC: 인증서 설치 (PC 마다 처음 한 번)

사내망 주소는 회사 자체 인증서를 씁니다. 설치하지 않으면 «연결이 비공개로 설정되어 있지 않습니다» 경고가 뜨고, 브라우저가 마이크를 허용하지 않습니다. 외부 참석자는 이 과정이 필요 없습니다.

  1. 서버 운영자에게 rootCA.pem 파일 하나만 받습니다. (이름에 key 가 들어간 파일은 절대 받거나 주지 않습니다.)
  2. Windows + R → certmgr.msc 입력 → Enter.
  3. 왼쪽에서 신뢰할 수 있는 루트 인증 기관 → 인증서 를 마우스 오른쪽 버튼으로 누르고 모든 작업 → 가져오기.
  4. 찾아보기 에서 받은 rootCA.pem 을 고릅니다(안 보이면 파일 형식을 모든 파일 (*.*) 로).
  5. 저장소가 신뢰할 수 있는 루트 인증 기관 인지 확인하고 다음 → 마침. 보안 경고가 뜨면 예.
  6. Chrome/Edge 를 완전히 닫았다가 다시 열고 사내망 주소로 접속합니다. 경고 없이 입장 화면이 나오면 끝입니다.

회사 정책으로 설치가 막히면 IT 담당자에게 요청하세요. 다른 Windows 계정으로 로그인하면 그 계정에서 다시 설치해야 할 수 있습니다.

3. 회의 만들기 (Host)

  1. 입장 화면 위쪽에서 회의 개설 을 고릅니다.
  2. 개설 코드 칸이 보이면 관리자에게 받은 코드를 넣습니다.
  3. 회의 만들기 를 누르면 회의 ID(9자리), 비밀번호(6자리), 초대 링크가 나옵니다.
  4. 복사 를 눌러 초대 링크를 참석 지점에 메신저 등으로 보냅니다. 링크에 비밀번호가 들어 있으니 참석 지점에만 보내세요.
  5. 아래의 지점 이름·언어·카메라·마이크를 정하고(4장과 같음), 전송 안내에 동의한 뒤 Host 로 입장.
알아 두기 회의가 끝나면 링크와 비밀번호는 바로 쓸 수 없게 됩니다. 만들어 놓고 오래 아무도 들어오지 않은 회의는 자동으로 지워집니다. 회의 중에도 상단의 초대 링크 버튼으로 링크를 다시 복사할 수 있습니다. 서버 PC 에서 localhost 로 열었어도 초대 링크는 이 PC 의 사내망 주소(https://<서버 IP>:8443)로 만들어집니다. 초대 링크는 같은 사내망 PC 용이고, 회사 밖 참석자에게는 외부 참석 링크를 보냅니다.

4. 회의 참여하기

  1. 초대 링크를 엽니다. 회의 ID 와 비밀번호가 자동으로 채워집니다. 링크가 없으면 회의 참여 를 고르고 직접 입력합니다.
  2. 지점 이름 — 예: «서울 회의실». 영상과 자막에 이 이름이 발언자로 표시됩니다.
  3. 이 지점의 언어 — 이 지점에서 말하는 언어이자, 자막을 받아 볼 언어입니다.
  4. 카메라·마이크 확인 을 누르고 브라우저가 권한을 물으면 허용. 미리보기에 얼굴이 보이고, 말하면 아래 막대가 움직이면 정상입니다. 장치가 여러 개면 카메라·마이크 목록에서 고릅니다.
  5. 전송 안내를 읽고 동의 칸에 체크하면 입장 버튼이 켜집니다.

입장 화면의 «자막» 표시

이 PC 의 브라우저가 음성 인식·번역을 할 수 있는지 미리 검사해 보여 줍니다. 회의 화면 상단에도 같은 표시가 있습니다. 표시에 마우스를 올리면 자세한 사유가 보입니다.

표시뜻할 일
자막 준비됨음성 인식과 번역 모두 가능그대로 사용
번역 일부 불가일부 언어만 번역 불가사유에 적힌 언어의 자막은 원문만 보입니다
번역 불가이 브라우저는 번역을 못 함최신 Chrome/Edge(PC) 로 다시 접속
음성 인식 불가이 지점의 말은 자동 자막이 되지 않음최신 Chrome/Edge(PC) 로 다시 접속. 원음 대화와 다른 지점 자막 보기는 됩니다

«처음 쓸 때 언어 모델 내려받기» 가 보이면, 입장 직후 브라우저가 번역용 언어 자료를 한 번 내려받습니다. 첫 자막이 조금 늦을 수 있습니다.

들어가지 못할 때

  • «회의 ID 또는 비밀번호가 올바르지 않습니다» — 링크를 다시 받거나 숫자를 확인하세요. 이미 끝난 회의일 수도 있습니다.
  • «이미 4곳이 접속해 있어…» — 지점 수가 꽉 찼습니다. 같은 회의실이면 한 PC 를 함께 쓰세요.
  • «이미 3개 언어를 쓰고 있어…» — 그 회의에 이미 다른 언어 3개가 있습니다. 이미 쓰는 언어 중 하나를 고르세요.

6. 자동 자막 · 마이크·스피커 끄기

버튼을 누르지 않고 그냥 말하면 됩니다. 원래 목소리는 항상 전달되고, 마이크가 켜져 있으면 이 지점의 말이 자동으로 글자로 바뀌어 각 지점의 언어로 번역된 자막이 뜹니다.

  • 지점의 언어로 또박또박 말합니다. 인식 중인 문장은 아래에 흐리게 보이다가(지점마다 한 줄), 문장이 끝나면 자막 기록에 확정됩니다.
  • 여러 지점이 동시에 말해도 각자 자막이 나오지만 섞여서 읽기 어렵습니다. 한 지점씩 말하세요.
  • 아래 상태 줄에 자동 자막 켜짐 · 인식 N문장 이 보입니다. «목소리 N초에 인식된 문장 0건» 이 보이면 아무것도 글자로 바뀌지 않은 것입니다. 지점 언어와 실제로 말한 언어가 같은지, 인터넷 연결을 확인하세요.

마이크·스피커 버튼

버튼누르면
마이크 켜짐 / 꺼짐내 목소리가 다른 지점에 가지 않고, 이 지점의 자동 자막도 바로 멈춥니다(음성 인식 서비스로도 보내지 않음). 누르는 순간 말하던 문장도 자막에 올라가지 않습니다. 다른 지점의 자막은 계속 보입니다. 다시 누르면 켜집니다.
스피커 켜짐 / 꺼짐다른 지점의 목소리와 번역 음성이 이 PC 에서 들리지 않습니다. 자막은 계속 보입니다. 이 PC 에만 적용됩니다.

스피커 소리가 자막으로 잘못 올라갈 때

스피커로 나온 다른 지점의 목소리를 이 지점 마이크가 다시 듣고, 이 지점이 말한 것처럼 자막을 만들 수 있습니다. 그래서 이 지점 마이크에 목소리가 들어온 직후의 인식만 자막으로 보내고 나머지는 버립니다. 버린 건수는 상태 줄에 «내 마이크에 목소리가 없어 버린 결과 N건» 으로 보입니다.

  • 그래도 엉뚱한 자막이 생기면 이어폰을 쓰거나 스피커 소리를 줄이세요.
  • 말했는데도 «버린 결과» 만 늘고 자막이 안 나오면 마이크 소리가 너무 작은 것입니다. 마이크에 가까이 대고 말하거나 다른 마이크를 고르세요.
주의 마이크가 켜져 있는 동안의 말은 글자로 바꾸기 위해 브라우저의 음성 인식 서비스(Chrome 은 Google)로 전송됩니다. 보내면 안 되는 이야기를 할 때는 마이크를 끄세요.

7. 자막과 번역 음성

  • 자막 한 줄은 발언 지점 · 시각(KST), 크게 보이는 번역문, 작게 보이는 원문으로 되어 있습니다. 같은 언어 지점이 말한 것은 원문 그대로 보입니다.
  • 번역은 각 PC 의 브라우저 안에서 이 지점 언어로 합니다. 잠깐 «번역 중…» 이 보일 수 있습니다.
  • «번역 불가 — 사유» 가 보이면 그 문장은 번역되지 않은 것입니다. 원문을 참고하세요.
  • 번역 음성: 켜짐 으로 바꾸면 다른 지점의 번역 자막을 이 PC 의 컴퓨터 목소리로 읽어 줍니다. 읽는 동안 상대 원음은 작아집니다. 처음에는 꺼져 있습니다. «(음성 없음)» 이 보이면 이 PC 에 그 언어 목소리가 없어 자막만 표시됩니다.

8. 화면 배치 · 화면 공유

화면 배치 (나에게만 적용)

배치보이는 방식
자동평소에는 바둑판, 누군가 화면을 공유하면 공유 화면을 크게
바둑판모든 지점을 같은 크기로
가로 한 줄모든 지점을 한 줄로
특정인 크게크게 볼 지점의 영상을 누르면 그 지점이 크게
말하는 사람 크게이 PC 에 들리는 소리가 가장 큰 지점을 크게(1.5초 이상 이어 말하면 바뀜)

영상 모서리의 확대 버튼을 누르면 그 영상이 모니터 전체로 커지고, 오른쪽 자막 칸은 그대로 보입니다(가운데 막대로 폭 조절도 됨). 전체 화면에서 다른 영상의 버튼을 누르면 그 영상으로 바뀝니다. Esc 나 같은 버튼으로 돌아옵니다. 전체 화면 중에는 아래 조작부가 보이지 않으므로, 마이크·스피커를 끄려면 먼저 돌아옵니다.

화면 공유

  1. 화면 공유 를 누르고 공유할 화면·창·탭을 고릅니다.
  2. 공유하는 동안에는 이 지점의 카메라 대신 공유 화면이 나갑니다. 공유 중지 를 누르면 카메라로 돌아갑니다.
  3. 한 번에 한 지점만 공유할 수 있습니다. 다른 지점이 공유 중이면 끝난 뒤 다시 시도하세요.

공유 화면을 크게 보는 동안에는 아래 설정이 접힙니다. 장치·배치 설정 펼치기 로 다시 엽니다. 화면 공유 중 보이는 «공유 화면 분석 · MOCK» 칸은 앞으로 넣을 AI 분석의 자리만 보여 주는 시험용 표시이며, 실제로 화면을 분석하지 않습니다.

9. 휴대폰 카메라 연결

화이트보드나 시제품처럼 PC 카메라로 비추기 어려운 것을 휴대폰으로 보여 줄 때 씁니다. 휴대폰은 영상만 보냅니다.

  1. 회의 화면 아래의 휴대폰 카메라 연결 을 누르면 QR 이 나옵니다.
  2. 휴대폰 기본 카메라로 QR 을 찍고, 열리는 페이지에서 카메라를 허용합니다.
  3. 회의 화면에 «지점 이름 · 현장 카메라» 영상이 추가됩니다.
  • QR 은 5분 동안 한 번만 쓸 수 있습니다. 만료되면 새 QR.
  • 지점마다 1대, 한 회의에 최대 2대까지 연결됩니다.
  • 사내망에서 연결할 때는 휴대폰이 같은 사내 Wi-Fi에 있어야 하고, 휴대폰에도 rootCA.pem 인증서가 설치돼 있어야 합니다. QR 이 안 찍히면 QR 이 안 찍히면 주소 보기 의 주소를 휴대폰에 직접 입력하세요.

10. 외부(다른 망) 참석자 초대

회사 밖이나 해외 사무실처럼 사내망에 들어올 수 없는 참석자용입니다. Host 가 사내망 주소로 접속해 있을 때만 버튼이 보입니다.

  1. 상단의 외부 참석 링크 를 누릅니다. 인터넷 주소를 여는 데 최대 40초쯤 걸립니다.
  2. 준비되면 외부용 초대 링크가 자동으로 복사됩니다. 외부 참석자에게 보냅니다.
  3. 외부 참석이 끝나면 외부 공개 끄기 를 누릅니다. 서버를 끌 때도 자동으로 닫힙니다.
  • 외부 링크 주소는 열 때마다 바뀝니다. 이전 링크는 다시 쓸 수 없습니다.
  • 외부 참석자와의 영상은 중계 서버를 거칠 수 있습니다. 이때 상단에 «외부 중계» 표시가 나오고, 영상 화질이 낮아집니다(360p).
  • 중계 서비스는 두 가지입니다. 기본은 Cloudflare(매달 1,000 GB 무료)이고, Host 는 상단의 중계: Cloudflare / Metered 목록에서 회의마다 바꿀 수 있습니다. 목록에는 각 서비스의 남은 양이 함께 보입니다. 회의 중에 바꾸면 모든 지점의 영상이 1~2초 끊겼다가 새 중계로 다시 연결됩니다.
  • Host 화면 상단에 지금 고른 중계의 사용량이 1분마다 갱신되어 보입니다. Cloudflare 는 Cloudflare · 최근 31일 1,000 GB 중 사용 … · 남은 …, Metered 는 중계 총량 · 사용 · 남은(이번 결제 주기) 입니다. · 내부 집계 가 붙으면 Cloudflare 조회가 잠시 안 돼 프로그램이 직접 센 양으로 판단 중이라는 뜻입니다. 사용량 확인 불가 가 보이면 표시 위에 마우스를 올려 이유를 확인하세요.
  • Cloudflare 무료 한도 보호 — 요금이 나가지 않도록 프로그램이 스스로 막습니다. 최근 31일 사용량이 900 GB 를 넘으면 표시가 주황색이 되고, 중계로 연결된 상대에게는 음성만 보냅니다(소리·자막은 그대로, 화면 공유는 1초에 1장). 사내망에서 접속한 Host 는 950 GB까지 영상 연장 을 눌러 그 회의만 영상을 다시 보낼 수 있습니다. 950 GB 에 닿으면 무조건 차단합니다 — 외부 참석자 연결이 끊기고 외부 참석 링크가 닫히며, 표시가 빨간색이 됩니다. 이때 Host 가 중계를 Metered 로 바꾸면 외부 참석을 다시 열 수 있습니다(자동으로 바뀌지는 않습니다). 31일 전 사용분이 빠지면 저절로 풀립니다.
  • Cloudflare 가 준비되지 않았으면(키 미설정·조회 실패) 상단에 외부 중계 없음 · Cloudflare 가 보이고, 회사 방화벽 뒤 참석자는 연결되지 않을 수 있습니다. 이때도 Host 가 Metered 로 바꿔 쓸 수 있습니다.
  • 무료 테스트용 연결이라 가끔 끊길 수 있습니다. 중요한 회의 전에는 미리 한 번 열어 보세요.

12. 연결이 끊겼을 때

  • 네트워크가 잠깐 끊기면 화면이 «재연결 중» 으로 바뀌고 30초 동안 자동으로 다시 연결합니다. 성공하면 같은 자리(Host 포함)로 돌아옵니다.
  • 끊긴 동안에는 자동 자막도 멈추고, 다시 연결되면 저절로 다시 켜집니다.
  • 30초 안에 돌아오지 못하면 입장 화면으로 돌아갑니다. 초대 링크로 다시 입장하세요.
  • Host 가 30초 넘게 돌아오지 않으면 가장 먼저 들어온 지점이 Host 를 넘겨받습니다. 원래 Host 가 다시 들어와도 되돌아가지 않습니다.

14. 저장되는 것과 전송되는 것

  • 영상·원음 — 참석 PC 끼리 직접 암호화해 주고받습니다. 서버에 저장하지 않습니다. 녹화 기능은 없습니다.
  • 마이크가 켜져 있는 동안의 말 — 자동 자막을 만들기 위해 브라우저의 음성 인식 서비스(Chrome 은 Google)로 전송됩니다. 마이크를 끄면 전송하지 않습니다.
  • 번역 — 각 PC 의 브라우저 안에서 처리합니다.
  • 자막 — 회의 중에만 서버 메모리에 있고, 회의가 끝나면 지워집니다.
  • 회의 정리 — Host 가 누를 때만, 고른 엔진의 회사로 자막이 전송됩니다.
  • 공유 화면 — 디스크에 저장하지 않습니다.

15. 서버 운영자용

서버 PC 의 프로젝트 폴더에서 실행합니다.

파일하는 일
run.bat서버 켜기. IP·인증서를 검사해 필요하면 같은 인증기관으로 인증서를 다시 만들고, HTTPS(8443) 로 시작해 브라우저를 엽니다. 창에 참석자용 주소가 표시됩니다. 이미 켜져 있으면 중복 실행하지 않고 브라우저만 엽니다.
program.bat회의 화면만 열기. 서버는 켜지 않습니다 — 서버가 켜져 있으면 이 PC 브라우저로 회의 화면을 열고 창이 바로 닫히며, 꺼져 있으면 «run.bat 을 먼저 실행» 안내를 띄우고 멈춥니다. 회의 화면 창을 닫았다가 다시 열 때 씁니다.
stop.bat서버 끄기. 8443 포트의 이 폴더 서버만 끄고(외부 참석 링크 포함), 다른 프로그램이면 끄지 않고 알려 줍니다.
  • 참석자에게는 certs\rootCA.pem 한 파일만 전달합니다. certs\ca 폴더와 *-key.pem 은 절대 공유하지 않습니다.
  • 서버 PC 의 IP 가 바뀌어도 run.bat 이 같은 인증기관으로 인증서를 다시 만들므로, 참석 PC 는 인증서를 다시 설치할 필요가 없습니다. 접속 주소만 바뀝니다.
  • 설정은 .env 에 둡니다. 주요 항목: ROOM_PASSCODE(회의 개설 코드 — 외부 참석 링크를 쓰려면 반드시 설정), SUMMARY_PROVIDER(기본 정리 엔진, claude 또는 codex), RELAY_PROVIDER(기본 중계, cloudflare 또는 metered), CLOUDFLARE_*·METERED_*(외부 중계). 값을 바꾸면 서버를 다시 켭니다.
  • Claude Code·Codex 정리는 서버 PC 에 각 프로그램이 설치·로그인돼 있어야 합니다.

자세한 설치·설정 절차는 프로젝트 폴더의 CLAUDE.md 에 있습니다.
